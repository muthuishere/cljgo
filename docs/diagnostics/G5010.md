# G5010 — maven coordinate not found

cljgo asked every configured Maven repository for a coordinate's `.pom` (or
`.jar`) and none of them served it.

```
error: maven coordinate org.clojure/tools.cli 9.9.9 not found in any repository
       tried https://repo.clojars.org — 404
       tried https://repo1.maven.org/maven2 — 404
help: run `cljgo explain G5010`
```

Every repository tried is named with the status it returned, so a 404 (no such
artifact) is distinguishable from a 500 or a network failure at a glance.

## What to do

- Check the group, artifact and version. The `dep` **name is the coordinate**:
  `"org.clojure/tools.cli"`. A single-segment name means group == artifact
  (`"medley"` ⇒ `medley/medley`), the Maven/Leiningen convention.
- Add the repository that hosts it with `(mvn-repo b "https://…")`, which
  prepends to the default list (Clojars, then Maven Central).
- Remember the artifact must actually be published: a library on GitHub but not
  on Clojars is a `:git` dependency, not an `:mvn/version` one.
