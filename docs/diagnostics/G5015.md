# G5015 — conflicting dependency coordinates

One `(dep …)` declaration carries more than one kind of fetch coordinate:
`:mvn/version` together with `:git` or `:path`.

```
error: dependency "medley" declares conflicting coordinates: :mvn/version and :git
help: keep one — :mvn/version (Clojars/Maven), :git, or :path
help: run `cljgo explain G5015`
```

## Why it is an error and not a precedence rule

A precedence rule would silently pick one and ignore the other, which is
exactly the class of quiet wrong answer cljgo's dependency layer is built to
avoid. There is no "primary" coordinate: they are three different ways of
identifying three different things.

## What to do

Keep exactly one:

```clojure
(dep b "org.clojure/tools.cli" {:mvn/version "1.1.230"})   ; Clojars/Maven
(dep b "greetlib"              {:git "https://…" :ref "v1.2.0"})
(dep b "sibling"               {:path "../sibling"})
```

For a Maven dependency the **name is the coordinate** (`group/artifact`), so a
Maven dep and a git dep can never collide by identity — they are necessarily
different names.
