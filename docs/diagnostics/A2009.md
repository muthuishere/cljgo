# A2009 — no such namespace

**Message patterns:** `no such namespace: <ns>`

## Cause

A qualified symbol (`ns/name`) names a namespace that does not exist in
this process: nothing has `require`d or `in-ns`'d it, and it is not an
alias of the current namespace.

Two causes dominate:

1. **A missing or misspelled `require`.** `(str/join ...)` without
   `(require '[clojure.string :as str])` reports `no such namespace: str`.
2. **A Java class.** cljgo is Clojure hosted on **Go** — there is no JVM,
   so `Thread/sleep`, `System/nanoTime`, `System/currentTimeMillis` and
   friends are not host statics but simply unknown namespaces. They fail
   LOUD here (ADR 0054 decision 4) rather than compiling to a silent nil.

## Example

```clojure
(System/nanoTime)
;; error: no such namespace: System at demo.clj:1:2
;; help: cljgo has no Java host — did you mean cljg.date/nano-time? (require '[cljg.date])
```

## Fix

Add the `require` (and check the alias spelling). For a Java static, use
the cljgo native equivalent:

| JVM                        | cljgo                     |
|----------------------------|---------------------------|
| `(Thread/sleep 100)`       | `(cljg.system/sleep 100)` |
| `(System/nanoTime)`        | `(cljg.date/nano-time)`   |
| `(System/currentTimeMillis)` | `(cljg.date/now)`       |
| `(System/getenv "HOME")`   | `(cljg.system/getenv "HOME")` |
| `(System/exit 1)`          | `(cljg.system/exit 1)`    |

Each lives in a lazily-loaded namespace: `(require '[cljg.system :as sys])`
or `(require '[cljg.date :as date])` first.
