# G5016 — replacement fn did not return a string

**Message pattern:** `clojure.string/<replace|replace-first>: the replacement
fn must return a string (found: <value>)`

## Cause

`clojure.string/replace` and `clojure.string/replace-first` accept a FUNCTION
as the replacement when the match is a regex pattern. That function is called
once per match and its return value is spliced into the result literally — so
it has to be a string.

```clojure
(require '[clojure.string :as str])
(str/replace "a1" #"\d" (fn [m] 42))   ; G5016
```

On the JVM this is a bare `ClassCastException: class java.lang.Long cannot be
cast to class java.lang.String`, thrown from `Matcher/quoteReplacement` far
from the call site (oracle: Clojure 1.12.5). cljgo names the fn's role and
shows the value instead.

## Fix

Return a string from the fn:

```clojure
(str/replace "a1" #"\d" (fn [m] (str 42)))   ;=> "a42"
```

`str` is the usual conversion. A character, a keyword, a number and `nil` are
all rejected — the JVM rejects them too.

## Notes

What the fn RECEIVES is `re-groups` of the match: the whole matched string when
the pattern has no capturing groups, a vector `[whole g1 g2 …]` when it does
(with `nil` for a group that did not participate).

The fn's result is used literally — `"$1"` is the two characters `$1`, not a
group reference. Use the string-replacement arity if you want `$1` expansion.
