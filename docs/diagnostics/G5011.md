# G5011 — unsupported Maven POM feature

cljgo's Maven resolver is a deliberately small, pure-Go subset: no JVM, no
`mvn`, no Aether. When a POM needs a feature the resolver does not implement,
it **names the feature and stops** — it never guesses (ADR 0095, spike s50
finding 1: a clear diagnostic beats a silent wrong version).

```
error: unsupported Maven POM feature in org.clojure/core.match 1.1.0: ${property} interpolation in a <version> (org.clojure/clojure ${clojure.version})
help: pin the version with (accept-version b "org.clojure/clojure" "1.12.0"), or depend on this library via :git or :path instead
help: run `cljgo explain G5011`
```

## The features that name-error

| feature | why guessing would be worse |
|---|---|
| `${property}` interpolation in a `<version>` | an uninterpolated version is a *wrong* version |
| `<dependencyManagement>` supplying a missing `<version>` | a silently-omitted version resolves to nothing, or to the wrong thing |
| `<parent>` POM inheritance | needed only to serve the two above |
| version ranges `[1.0,2.0)` | requires a solver; cljgo has none, by design |
| `-SNAPSHOT` versions | mutable identity, incompatible with a content-verified lock |
| `<profiles>` | conditional graphs; Aether surface |
| `<classifier>` | a non-default artifact; out of scope |
| `<packaging>` other than `jar`/`bundle` | there is no jar to extract |

## What is IN scope

`<groupId>`/`<artifactId>`/`<version>`, `<dependencies>`, `<scope>`,
`<optional>`, `<exclusions>` (including `*` wildcards), `.sha1` verification,
and multi-repository fallback.

## What to do

- Pin the offending coordinate yourself with `accept-version`, which stops the
  resolver from needing the POM's own answer.
- Or depend on the library through `:git`/`:path`, where nothing needs a POM.
- Note that `org.clojure/clojure`, `org.clojure/spec.alpha` and
  `org.clojure/core.specs.alpha` are **pruned** from every graph before this
  check runs (cljgo *is* the Clojure implementation), which already removes the
  most common `${clojure.version}` case in the wild.
