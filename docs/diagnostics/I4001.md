# I4001 — Java class used as a namespace

**Message pattern:** `no such namespace: <Class> (<Class> is a Java class, not
a namespace: cljgo hosts Clojure on Go, so the Java static <Class>/<member> is
unavailable)`

## Cause

`Integer/parseInt`, `Math/sqrt`, `System/currentTimeMillis` and friends are
Java **static** calls: the part before the `/` names a JVM class, not a Clojure
namespace. cljgo hosts Clojure on **Go**, not the JVM — there is no
`java.lang.Integer`, so there are no statics on it to call.

Before this code existed the failure read only `no such namespace: Integer`,
which pointed at the wrong thing: nobody was ever going to find or `require` a
namespace called `Integer`. The diagnosis now names what the symbol actually
is, and — for the idioms that have a direct clojure.core replacement — the
render layer appends a `help: did you mean …?` line.

## Example

```clojure
(Integer/parseInt "42")     ; help: did you mean parse-long?
(Double/parseDouble "1.5")  ; help: did you mean parse-double?
(String/valueOf 42)         ; help: did you mean str?
```

## Fix

Use the portable clojure.core function instead of the Java static. These are
real clojure.core fns (JVM Clojure 1.12.5 has them too), so the replacement
runs unchanged on both hosts:

| Java static | cljgo / clojure.core |
|---|---|
| `Integer/parseInt`, `Long/parseLong`, `Integer/valueOf`, `Long/valueOf` | `parse-long` |
| `Double/parseDouble`, `Float/parseFloat`, `Double/valueOf` | `parse-double` |
| `Boolean/parseBoolean`, `Boolean/valueOf` | `parse-boolean` |
| `Integer/toString`, `Long/toString`, `Double/toString`, `String/valueOf` | `str` |
| `Math/abs` | `abs` |
| `String/format` | `format` |

(Every replacement above is a real clojure.core fn on **both** hosts, so the
rewrite still runs on the JVM.)

For anything without a clojure.core equivalent (`System/currentTimeMillis`,
`Thread/sleep`, `Math/sqrt`), reach for the Go host instead — `(require-go
'[math])` then `(math/Sqrt 2.0)` — rather than the JVM class.
